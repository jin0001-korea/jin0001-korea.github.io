SLOPE · 기존 연결을 유지하는 수정판

채팅+ 수집 수정 v11

기존 연결파일에서 채팅+ 수집 작업을 수정합니다. 발신 사진의 실제 파일 크기와 대화 상대 번호를 확인하는 방식을 보완합니다.

기존 연결키와 수집 시작 시각을 유지합니다. 과거 문자 재업로드나 연결키 재발급은 필요하지 않습니다.

1 · 파일 준비

기존 연결파일 선택

이 휴대폰에 설치한 SLOPE 전체 .prj.xml 파일을 선택하세요. 문자 백업 XML이나 진단 파일은 사용할 수 없습니다.

수정할 프로젝트수정 후 실행할 작업
기존 파일이 없으면

Tasker 하단의 해당 SLOPE 수신 프로젝트 탭을 길게 눌러 Export / 내보내기 → XML to Storage / 저장소에 XML로 저장한 뒤 선택하세요. 채팅+ 작업 하나가 아닌 전체 프로젝트를 내보냅니다.

선택한 파일은 이 브라우저 안에서만 처리합니다. 연결키나 파일을 서버로 보내지 않습니다.

2 · 휴대폰에 적용

해당 프로젝트 교체

  1. 수정 파일을 내려받은 뒤 Tasker 하단에서 위에 표시된 같은 SLOPE 수신 프로젝트를 길게 누릅니다.
  2. Delete Contents / 내용까지 삭제로 해당 프로젝트의 작업·프로필을 함께 삭제합니다. 다른 프로젝트는 유지하세요.
  3. 하단 프로젝트 탭의 Import Project / 가져오기로 새 SLOPE-RCS-v11-….prj.xml을 추가합니다.
  4. 채팅+ 동기화 v11 작업을 한 번 실행합니다. 이후 2분 간격으로 이어서 처리합니다. 밀린 사진은 여러 차례에 나눠 가져옵니다.

휴대폰의 문자·사진과 사이트 저장 내역은 유지됩니다. Tasker 앱 데이터 자체를 삭제하거나 초기화하지 마세요.

이미 있는 프로젝트라는 메시지가 뜨면 이전 프로젝트의 작업·프로필까지 삭제했는지 확인하세요. 이름만 바꿔 추가하면 자동 수집이 중복 실행될 수 있습니다.
